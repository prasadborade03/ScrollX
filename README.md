## About

ScrollX is a mobile mini-game platform built around quick, simple, and addictive games.

Pick a game, play for a few minutes, earn XP, and compete on the leaderboard.

## Games

ScrollX includes a growing collection of mini-games:

- Slide Puzzle
- Trivia Quiz
- Memory Match
- Color Match
- Math Blitz
- Word Scramble
- Reaction Tap
- Number Sequence
- Simon Says
- Snake Lite
- Typing Speed
- Odd One Out
- Pattern Memory
- Balloon Pop
- Guess the Flag
- Falling Catch
- Countdown Clicker
- Anagram Rush
- Shape Tap
- Whack-a-Mole
- Equation Pairs

## Features

- Quick mini-games
- XP and scoring
- Global leaderboard
- Player profiles
- Game categories
- Audio and haptic feedback
- Social interactions
- Simple, tactile UI
